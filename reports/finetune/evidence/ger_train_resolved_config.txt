-- collator, the defect a resolved config should have caught ------
  imported from transformers: ['AutoModelForCausalLM', 'AutoTokenizer', 'Trainer', 'TrainingArguments']
  DataCollatorForLanguageModeling imported: False
  PromptMaskedCollator defined locally:    True
  WHY: DataCollatorForLanguageModeling(tok, mlm=False) (a) cannot pad `labels` --
    PreTrainedTokenizerBase._pad pads only model_input_names[0], attention_mask,
    token_type_ids and special_tokens_mask -- so ragged prompt-masked labels raise
    "Unable to create tensor ... (labels in this case)"; and (b) its torch_call
    OVERWRITES labels with a clone of input_ids, discarding the prompt mask, and then
    sets labels[labels == pad_token_id] = -100 which (pad_token = eos_token here) masks
    the training EOS so the model never learns to stop.
  Both reproduced against the installed transformers 4.57.6; see tests/test_ger_train.py.
